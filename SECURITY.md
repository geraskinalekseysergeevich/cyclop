# Безопасность

## Сеть и локальные данные

Cyclop не содержит сторонних SwiftPM-пакетов и не отправляет собственных
сетевых запросов. Курсы валют читаются только из локальных файлов:

```text
~/Library/Application Support/Cyclop/currency-rates/currencies/<код>.min.json
```

Файл должен содержать таблицу для валюты, выбранной источником, например:

```json
{"date":"2026-10-29","usd":{"eur":0.86,"rub":80.0}}
```

`<код>` — трёхбуквенный код источника в нижнем регистре, например `usd`. В
таблице указываются курсы относительно одной единицы этой валюты. Cyclop не
обновляет файлы и показывает дату из файла. Без файла конвертер сообщает, где
его искать. Обновление и передача этого файла — ответственность пользователя
или ИТ.

Music читает состояние плееров через MediaRemote: локальный helper собран из
исходников проекта и загружается в системный `/usr/bin/perl`. Он обращается к
частному фреймворку Apple `MediaRemote.framework`, не к публичному API. Это
самая нестандартная часть сборки: поведение может измениться после обновления
macOS, а корпоративная проверка может потребовать убрать Music. Spotify
обложки через сеть не загружаются. Calendar читает события через EventKit.
Нажатие на ссылку встречи передаёт URL браузеру или приложению по умолчанию —
дальше соединение выполняет уже оно.

Перевод использует `Translation.framework`. При установленном языковом пакете
перевод выполняется на устройстве. macOS может предложить скачать отсутствующий
пакет. Universal Clipboard также обслуживается macOS: Cyclop читает содержимое,
которое система поместила в общий буфер.

Это статическая проверка кода. Сетевой трафик готового приложения отдельно не
снимался; системные службы macOS и открытые пользователем приложения находятся
вне контроля Cyclop.

## Разрешения

При запуске разрешения не запрашиваются.

- **Calendar:** вкладка календаря читает события после системного запроса
  доступа.
- **Apple Events / Automation:** управление Apple Music и Spotify выполняется
  через AppleScript; macOS может запросить разрешение для соответствующего
  плеера.
- **Accessibility:** блокировка клавиатуры в Utilities перехватывает системные
  нажатия только пока блокировка активна.
- **Файлы:** доступ к выбранным через системный диалог файлам выдаёт macOS.

Запись экрана не требуется.

## Что приложение читает и хранит

- **Буфер обмена:** последние 40 копирований хранятся только в памяти процесса.
  Копирования с типом `org.nspasteboard.ConcealedType` пропускаются.
- **Снимки из буфера:** сохраняются в `~/Pictures/Cyclop` и автоматически не
  удаляются. Настройка позволяет отключить сохранение.
- **Полка:** сохраняет пути к файлам, а не их копии.
- **Заготовки:** обычный текст в
  `~/Library/Application Support/Cyclop/snippets.json`.
- **Заметки:** `~/Library/Application Support/Cyclop/notes.json`.
- **Валюта:** локальные файлы курсов в указанном выше каталоге.

## Сборка

SwiftPM не подключает внешние пакеты. Helper для Now Playing собирается локально
из `Sources/CyclopMediaHelper/helper.m`. `Scripts/bundle.sh` по умолчанию
создаёт ad-hoc подписанную, не нотарифицированную сборку. Для корпоративного
распространения организация может подписать её своим Developer ID.
